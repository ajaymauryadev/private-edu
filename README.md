# Bachpan Public School HTML Template

## Overview
This project contains a simple, responsive static HTML5 website template for a fictional school named Bachpan Public School. It is structured to be easy to convert later into a native WordPress Gutenberg block theme.

## Folder structure
- index.html — homepage
- about.html — about page
- academics.html — academics page
- admissions.html — admissions page
- blog.html — blog/news archive
- single.html — single post page
- contact.html — contact page
- 404.html — error page
- assets/css — design tokens, base, layout, component, utility, and responsive styles
- assets/js — minimal JavaScript for the mobile navigation
- assets/images — placeholder SVG and JPG-like image paths for future replacement


## CSS architecture
The styles are split into focused files:
- tokens.css for design variables
- base.css for resets and typography
- layout.css for page structure
- components.css for reusable UI blocks
- utilities.css for a small set of helper classes
- responsive.css for mobile-first media queries

## JavaScript functionality
The script adds a simple mobile navigation toggle and updates the menu button state with aria-expanded.

## Accessibility notes
The template includes:
- a skip link
- semantic landmarks
- descriptive alt text
- visible keyboard focus styling
- labels for form fields
- a mobile menu with accessibility attributes
